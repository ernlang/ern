## Périmètre (MM-02)
- MM-02.2 Allocation abstraite : identité, base, étendue, alignement, état vivant/mort, octets, autorité de désallocation.
- MM-02.3 Octet abstrait : `uninit | init (valeur) (provenance optionnelle)`.
- MM-02.4 Emplacement (place) : allocation + plage. La spec le distingue du moyen d'accès : modéliser `Place` et `Access` comme deux structures.
- MM-02.5 Moyen d'accès : adresse, provenance (= identité d'allocation en v0.1, sans étiquette), plage, autorité (`read | write`, avec `read ≤ write`).
- MM-02.A Identité : fraîcheur, non-réutilisation ; une adresse est réutilisable.
- MM-02.B Lecture : conditions 1, 2, 3, 5 modélisées. 4 (représentation typée), 6 (alignement), 7 (concurrence) : abstraites, par un paramètre de prédicat ou par omission, au choix, mais documenté.
- MM-02.C Écriture : 1, 2, 3, 5, 6 modélisées ; 4 (valeur admissible) abstraite.
- MM-02.D Désallocation : allocation vivante, autorité compatible. Modéliser la compatibilité comme une relation paramétrique `Compatible : Nat → Nat → Prop`, pas comme une égalité.
- MM-02.E Dérivation : sous-plage, même provenance, autorité ≤ origine. La formation d'une adresse hors limites n'est pas modélisée comme UB (la spec la laisse ouverte).
- Hors périmètre : MM-02.F (data races), MM-02.G (conversions), tout MM-03.

## Théorèmes à prouver (noms imposés)
- `read_requires_live` (P1)
- `dealloc_invalidates` (P2a)
- `reuse_does_not_restore` (P2b) — la base de la nouvelle allocation est universellement quantifiée : elle peut être exactement celle de l'ancienne. C'est le contenu de MM-02.A ; une version avec base différente est sans valeur.
- `no_double_free` (P2c)
- `write_initializes` (P3)
- `derive_spatial`, `derive_prov`, `derive_auth_le` (P4)
- `alloc_fresh`, `alloc_wf`, `dealloc_wf`, `write_wf` (invariant de fraîcheur des identités)
Si un théorème n'est pas prouvable à partir des règles telles qu'écrites, ne renforce pas les définitions pour le faire passer : signale-le avec le contre-exemple.

- `lake build` passe depuis `formal/`.
- Rien au-delà du périmètre.
- Commits atomiques sur la branche, messages en français.

2. `formal/reports/MM02_v0.2.md`, lisible sans ouvrir le Lean (le répertoire `reports/` est de l'exploration : il ne sera jamais mergé dans la branche par défaut) :

   (e) questions pour arbitrage.

## Arbitrages (font foi pour cette passe)
- La sémantique normative des opérations brutes est une relation de transition ; une obligation violée, statique comprise, est une issue `ub`.
